# Consistent season lists

User explicitly requests replacing the different single-season number/multi-season count presentations with one list similar to Local seasons. Every comparable card will use a labeled Missing seasons or Partial seasons list, with compact numeric chips. Buttons retain accessible Season N names, selected state and per-season coverage/details. Remove the large header number/count in both cases. Keep review states and responsive grouping unchanged.

Server question is answered from current source, not expanded into new multi-host work: one global SSH config owns multiple folder roots; multiple encrypted Jellyfin/Plex metadata connections are supported; card server badges/filters and per-server availability are not implemented. This UI change introduces neither inferred server identity nor new inventory semantics.
