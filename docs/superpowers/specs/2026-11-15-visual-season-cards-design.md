# Visual missing-season cards

User requests a more visual missing-season view comparable to the existing Overview, authorizing an implementation trial. Keep all comparison semantics and API unchanged. Use existing series artwork through the same bounded local proxy (series artwork, not invented season artwork), with an honest fallback if unavailable. Each season gets a poster-led card, clear state badge, prominent season number, accessible proportional aired-episode coverage bar, and chips for recognized local seasons. Missing episode numbers and data freshness remain expandable. Review cards use explicit uncertainty and no numerical coverage claim. Two columns on desktop, one on phones; existing themes and bilingual controls retained. No new dependencies, provider payloads, NAS operations or notification changes.

Chosen implementation: extract a focused SeasonGapCard component, sharing the existing response type with the list. Reuse artwork rather than generate decorative imagery; use coverage ratios rather than inferred present-episode numbers because the API supplies only absent numbers. Render missing-number chips only when expanded. Artwork errors and long titles must remain usable. Preserve paging/search/poll recovery and title links.
